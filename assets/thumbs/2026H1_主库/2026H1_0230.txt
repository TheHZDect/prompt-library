输出一份可读、可选、可收藏的取名方案。海报要同时具备古风诗意、文化艺术氛围和现代设计感，不是普通信息图。

三、命理推演要求
先完成命理推导，再进入取名：
排盘 → 日主强弱 → 格局判定 → 五行旺衰与喜用神 → 十神分析 → 大运流年简述 → 选字方向 → 候选组合。
公司名额外考虑：
行业五行属性 + 创始人喜用神 + 品牌音律 + 传播记忆度。
若信息不足，如公司创始人缺少出生时辰，必须说明：
“因未提供出生时辰，以下按三柱参考，不作完整时柱精排。”
不得假装精准排盘。
四、文字内容要求
每个取名对象需包含：
1. 命理速览，控制在200字以内：
四柱八字｜日主强弱｜格局｜喜用神 / 忌神｜一句话气质点评。
2. 候选名3个。
每个候选名从5个维度简析，每项1–2句：
- 五行补益：补什么五行，调和什么问题。
- 字义内涵：逐字解释本义、引申义、文化出处。
- 三才五格：天格、人格、地格、外格、总格，说明吉凶与核心象意。
- 音律字形：平仄、声韵、书写结构、美感。
- 卦象寓意：卦象图、卦名、卦义简析。
3. 首推名 + 一句话理由。
三个候选名气质要有差异：稳重 / 灵动 / 文雅，不能雷同。
五、海报结构
每张海报为单图三卡对比。严禁出现“A区 / B区 / C区”等分区文字。
海报自上而下包含：
1. 主标题
人名海报标题：「欧阳 · 取名建议」
公司海报标题：「AI智能硬件品牌 · 取名建议」
标题使用大气手写字，字号最大。
标题旁点缀朱红小印章或落款。
副标题一行，点明“命理取名 / 说人话型 / 风格关键词”。
2. 命主信息区
两行展示：
第一行：用户输入信息。
第二行：命理推算信息，包括四柱、日主强弱、格局、喜用神、忌神、一句话点评。
两行靠底色深浅区分，不使用硬分隔线。
3. 取名推导链
横向流程图：
四柱 → 日主 → 喜用神 → 选字方向 → 候选三名。
节点配小图标，箭头连接，清楚展示“为什么这么取”。
4. 候选名卡片
三个候选名等宽并列，作为视觉主体。
每张卡片包含：
- 名字大字：手写体居中，字号最大。
- 拼音 + 平仄：浅灰小字。
- 首推角标：仅首推卡片使用“首推”印章或斜角标。
- 五行补益：一句话，≤18字。
- 字义内涵：一句话，≤18字。
- 三才五格：一句话，≤18字。
- 音律字形：一句话，≤18字。
- 卦象寓意：卦象图 + 卦名 + 一句话。
- 名字之魂：≤14字，提炼核心气质。
- 综合评分 + 气质标签。
5. 底部首推收尾
格式：
「首推：名字——一句话理由」
居中呈现，末尾可加朱红印章：老杨取名。
六、排版要求
- 严禁横向对比表，三张卡片本身就是对比。
- 严禁出现“A区 / B区 / C区”等结构字样。
- 不用明显黑色边框或粗分割线。
- 依靠留白、字体层级、底色微差、印章和纹样组织信息。
- 卡片之间要有明显呼吸感，不能拥挤。
- 首推卡片居中，用印章、角标、浅金底色或微描金强化。
- 主次层级：名字大字 > 名字之魂 > 评分 > 五维解析 > 拼音平仄。
- 信息要清楚、耐看，不要堆字。
