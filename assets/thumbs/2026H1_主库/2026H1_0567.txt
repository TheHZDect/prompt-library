为虚构的游戏、平台或收藏系统 [DROP NAME] 创作一个高级且极具真实感的抽奖箱 / 扭蛋发布广告。
目标是让这次发布显得极具吸引力、价值感、视觉冲击力，并能让玩家或收藏家一眼识别为必须入手的限量扭蛋活动。它应当看起来像是一场官方的商业化活动、抽卡横幅、盲盒宣传或扭蛋系列广告，具有强烈的稀有度张力和炒作感。
发布详情：
- 发布名称：[DROP NAME]
- 发布类型：[抽奖箱 / 抽卡横幅 / 盲盒 / 扭蛋发布 / 神秘礼包 / 活动捆绑包 / 召唤横幅]
- 平台 / 游戏 / 世界观：[所处环境]
- 核心概念：[此发布包含的内容]
- 核心幻想：[人们希望抽中 / 解锁 / 拥有的内容]
- 受众：[受众群体]
- 语调：[造势 / 奢华 / 狂热 / 史诗 / 可爱 / 神秘 / 威望 / 触电感]
- 文化氛围：[原神风格 / 移动端抽卡 / 街头服饰发布 / 泡泡玛特 / 电竞商店 / 动漫周边 / Y2K 游戏核心 / 高级数字资产]
- 真实程度：[可信的在线游戏 / 可信的收藏品发布 / 风格化但真实 / 冷面虚构]
广告结构：
像官方发布或召唤活动一样构建视觉效果。
包含以下板块：
- 发布标题
- 英雄道具、皮肤或主打抽取物
- 稀有度等级
- 抽取池或主打阵容
- 概率提示或稀有度信号
- 活动持续时间
- 可选的价格或货币
- 可选的“限时”横幅
- 可选的保底奖励说明
- 可选的活动图标或包装艺术
- 可选的“立即开启”或“召唤”行动号召 (CTA)
文案要求：
- 一个强有力的发布标题
- 1 到 3 行辅助文案
- 符合游戏或收藏家文化的短语造势语言
- 紧迫感、渴望感和系统清晰度之间的平衡
- 听起来专业官方而非通用的措辞
包含：
- 强有力的发布标题处理
- 高级的稀有度层级
- 视觉特征明显的特色物品
- 可信的商业化线索
- 强烈的活动时效 / 稀缺性信号
- 精致的平台原生 UI 语言
- 清晰的价值幻想
- 极具传播力的收藏家狂热能量
视觉方向：
- 让广告看起来像是一个人们会立即花钱参与的真实在线活动
- 强调稀有度、独特性、情感吸引力和闪耀的渴望感
- 平衡商业化设计与精致的视觉世界观构建
- 适用于社交媒体发布帖子、游戏内商店横幅、活动宣传图或收藏文化内容
- 最终效果应看起来像是来自成功平台或游戏的真实限时发布活动
美术指导：
- 风格：[移动端抽卡横幅 / 高级收藏品发布广告 / 动漫召唤屏幕 / 街机扭蛋海报 / 数字商店活动 / 潮流玩具发布]
- 配色方案：[配色]
- 字体感受：[大胆造势无衬线体 / 整洁的游戏 UI / 高级发布字体 / 动漫活动显示 / 收藏家标签]
- 材质感：[游戏内商店横幅 / 移动端活动屏幕 / 数字发布海报 / 扭蛋机活动 / 商店面板]
- 灯光或图像氛围：[发光 / 触电 / 电影感 / 糖果流行 / 暗黑威望 / 战利品揭示光泽]
- 背景：[UI 空间 / 星空 / 扭蛋机 / 召唤虚空 / 活动舞台 / 数字商店背景]
构图：
- 将广告展示为一个统一的活动宣传图像
- 使主打奖励、稀有度层级和活动时间一眼可见
- 使用真实的商店横幅层级和商业化逻辑
- 让发布显得诱人、有限且在系统上具有可信度
- 最终输出应具有病毒式传播潜力，看起来像高级的虚构抽奖广告
输出质量：
- 极其详细
- 视觉结构化
- 商业可信度高
- 文化流利度强
- 精致的发布系统造型
- 强大的层级和间距
- 高级的活动横幅构图
- 即时分享的视觉概念
可选内容块：
- 保底 / 概率说明
- 掉率条
- 活动倒计时
- 游戏内货币图标
- 扭蛋艺术图
- “全新专属”标签
- 赛季标记
- 联名徽章
- 预览轮播图
- 行动号召按钮
避免：
- 通用的奖励图标
- 薄弱的稀有度逻辑
- 看起来很假的人造商业线索
- 凌乱的横幅设计
- 随机的字体选择
- 业余的活动美学
- 过多的文案掩盖主打物品
- 明显的恶搞（除非刻意选择）
