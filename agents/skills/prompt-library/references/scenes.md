# 场景标签（facet，不参与分族）

用法：`search "<关键词>" --scene <id>`。同一场景跨所有族都存在。
判定只用定域证据（核心元素段权重 2、画面风格段权重 1），背景顺带提到不计，**无证据的条目该字段为空**。

## 室内 / Indoor  `indoor`（1553 条）

人物或主体处于室内空间，靠窗光与陈设叙事。

### 写作要点
- 写明空间类型与关键家具（窗边木桌、纱帘、书架、绿植）。
- 交代光线入口：窗光方向、室内灯色温。
- 前景放一件实物（杯子、书、花）建立纵深。

### 常见翻车
- 家具罗列过多，抢掉主体。
- 窗光与灯光色温互相打架。

触发词：室内, 房间, 窗边, 卧室, 客厅, 走廊, 教室, 工作室, 窗台, 阳台, 屋内, 窗前

## 街头 / Street  `street`（943 条）

街道、店面前、夜色路灯下，强调现场感与生活气息。

### 写作要点
- 指定机位高度与镜头感（胸口平视、35mm、低角度）。
- 交代街景元素：招牌、路灯、行人虚化、路面反光。
- 夜景写光斑与逆光轮廓。

### 常见翻车
- 背景行人车辆干扰主体。
- 把街头拍成棚拍纯色背景。

触发词：街道, 街景, 马路, 人行道, 巷子, 路口, 天台, 街头, 路面, 斑马线, 街拍

## 都市 / Cityscape  `city`（1059 条）

天际线、地标、商圈作大面积背景，强调尺度与现代感。

### 写作要点
- 点名地标与方位关系。
- 人物与建筑形成尺度对比。
- 选黄昏或蓝调夜景统一色温。

### 常见翻车
- 地标画错或张冠李戴。
- 楼群糊成一片缺少层次。

触发词：城市, 天际线, 高楼, 摩天楼, 建筑群, 商业区, 都市, 楼宇

## 古建 / Historic Setting  `historic`（593 条）

古镇、宫殿、园林、回廊、寺庙作场景。

### 写作要点
- 写明建筑构件（飞檐、格栅、石拱桥、红灯笼）。
- 用构件作前景框，制造纵深。
- 夜景以灯笼／烛火为唯一暖光源。

### 常见翻车
- 不同地域朝代建筑混搭。
- 结构透视易出错，需限定视角。

触发词：古镇, 故宫, 宫殿, 寺庙, 庭院, 园林, 城墙, 废墟, 遗迹, 庙宇, 古建筑, 石窟, 洞窟, 回廊, 廊道, 牌楼, 佛塔, 古塔, 灯塔

## 自然 / Nature  `nature`（565 条）

森林、花海、山野、湖边等户外自然环境。

### 写作要点
- 点到物种与季节（樱花、绣球、枯草、雪松）。
- 给时间天气（晨雾、雨后、逆光黄昏）。
- 前景中景远景分别指定植被。

### 常见翻车
- 植物种类不指定导致形态错。
- 全景无焦点。

触发词：森林, 草原, 山野, 山谷, 溪流, 湖水, 田野, 花田, 花海, 草地, 湖边

## 海边 / Seaside  `seaside`（315 条）

海滩、礁石、泳池、游艇等水岸场景。

### 写作要点
- 定潮汐与水面状态（平静、白浪、反光）。
- 交代天空与海平面的比例。
- 阳光方向决定人物阴影与水的颜色。

### 常见翻车
- 海天一色没有层次。
- 湿身衣物与沙滩细节被忽略。

触发词：海边, 沙滩, 海滩, 海浪, 泳池, 海岛, 海岸, 礁石

## 店铺 / Shop / Café  `cafe`（289 条）

咖啡馆、书店、便利店、甜品店等小店空间。

### 写作要点
- 写明柜台、陈列与招牌内容。
- 用商品或橱窗作前景遮挡。
- 暖光吊灯与玻璃反光制造氛围。

### 常见翻车
- 招牌文字乱码，需限制可读文字。
- 陈列过密失主体。

触发词：咖啡馆, 咖啡店, 餐厅, 书店, 图书馆, 酒吧, 面包店, 便利店, 超市

## 星夜 / Night Sky  `night`（161 条）

夜空、月色、霓虹夜色为主导光线。

### 写作要点
- 定月相或星空密度。
- 地面要有一个光源（灯、篝火、霓虹）解释主体照明。
- 控制噪点与蓝调色温。

### 常见翻车
- 夜空亮得像白天。
- 主体无光源却要求清晰。

触发词：夜空, 星空, 月光, 深夜, 月色, 夜色, 星夜

## 雪景 / Snow  `snow`（142 条）

雪地、飘雪、冬日场景。

### 写作要点
- 写雪的状态（新雪、结冰、飘雪中）。
- 给人物合理冬季服饰与材质。
- 冷调环境配一处暖光形成对比。

### 常见翻车
- 雪地把人脸照成蓝灰死色。
- 雪粒细节糊成一团。

触发词：雪景, 雪地, 飘雪, 雪山, 冬日, 霜雪
