# 电商与品牌物料 / E-commerce & Brand Assets

- ID: `ecom`
- 父族: `ecom`
- 规模: 41 条
- 常见风格: 高级质感, 清新治愈, 写实, 极简

## 适用
要主图、详情页、卖点图这类电商视觉，或品牌 Logo／徽章／VI 套件这类商业物料时用它。
EN: Marketplace images and detail pages, or brand logo / VI asset sheets.

## 写法要点
- 定模块顺序（主图→卖点→参数→场景）。
- 每模块给标题与一句卖点文案。
- 产品角度与背景纯度要求明确。
- 价格／参数标签内容写死，避免乱码。
- 品牌物料类（Logo／徽章／VI 板）给主副标、色板、字体与应用场景四组。

## 常见翻车
- 信息层级混乱，卖点被淹没。
- 参数文字过多导致错字。
- 电商详情与品牌规范混在一张图时，先声明交付物是哪一种。
