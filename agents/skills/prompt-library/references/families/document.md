# 文档排版 / Document Layout

- ID: `document`
- 父族: `document`
- 规模: 2 条
- 常见风格: 写实, 复古胶片, 电影感

## 适用
要报纸、杂志页、简历、书页这类版面设计时用它。
EN: Newspaper, magazine, resume or book page layouts.

## 写法要点
- 定版面结构（几栏、报头位置、图片占位）。
- 标题与正文层级字号关系写清。
- 给可辨识的小语种文字样例并限制密度。
- 纸张材质与折痕等真实感细节。

## 常见翻车
- 小字必乱码，要显式允许模糊处理。
- 版式与内容主题不匹配。
