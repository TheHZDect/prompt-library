## 写法要点
- 颗粒与褪色程度要量化（轻／中，高光是否偏奶白）。
- 指定复古色板：港风暖红、民国淡雅、西式芥黄。
- 服装单品具体（丝绒吊带、大波浪、怀表链、皮带相机）。
- 场景选老街／出租屋／站台，并交代光源年代感（白炽灯、霓虹）。

## 常见翻车

- 复古元素堆过头，变成 cosplay 造型照。
