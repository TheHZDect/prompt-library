# 信息图表 / Infographic

- ID: `infographic`
- 父族: `infographic`
- 规模: 120 条
- 常见风格: 高级质感, 写实, 时尚商业, 电影感

## 适用
要图表、知识卡、时间线、流程说明这类信息图时用它。
EN: Explainer graphics, timelines, knowledge cards, charts.

## 写法要点
- 列 3–5 个信息模块与先后顺序，每模块给标题与要点。
- 定版式栅格（左右分栏／中心放射／纵向时间轴）。
- 文字要短标签，明确"不要长段落"。
- 配色分组的语义（一类一色）与图标风格。

## 常见翻车
- 把长段正文塞进画面，字小且乱码。
- 模块过多导致挤成一团。
