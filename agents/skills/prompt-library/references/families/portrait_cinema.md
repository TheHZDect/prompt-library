## 写法要点
- 先定主光源与反差比（侧逆光、单灯、车窗漫光）。
- 给一个能承担叙事的元素（雨、车站、霓虹、烟、玻璃反射）。
- 统一冷暖撞色，说明阴影倾向（青橙／冷蓝／暖金）。
- 选一种镜头语言并写死：广角近身 或 长焦压缩，不要两者都要。

## 常见翻车
- 只写"电影感"不给光色，等于没写。
- 戏剧光影过强，把皮肤细节全吞掉。
