# 人像·写实 / Realistic Portrait

- ID: `portrait_real`
- 父族: `portrait_real`
- 规模: 3400 条
- 常见风格: 写实, 清新治愈, 时尚商业, 高级质感

## 适用
要一张有真实皮肤、发丝与布料质感的人物照片，不特指地域流派时用它。
EN: One realistic person photo where skin, hair and fabric detail matter.

## 写法要点
- 先定景别与机位：近景特写／中景／全身，并交代人物在画面中的位置。
- 分前景—中景—远景三层写，每层给具体物体，而不是笼统"虚化背景"。
- 发色发型、服装单品与材质逐项写实（如"黑色齐刘海长直发""米白针织开衫"）。
- 给光源方向与色温（窗光侧逆、暖黄路灯），不要只写"光线好看"。

## 常见翻车
- 只堆"8K/超高清/极致"却没有主体细节，画面会被随机填补。
- 同时要求多种冲突风格（写实+动漫+水墨），结果哪个都不到位。
- 前景中景远景不分，人物与背景互相抢焦点。
