# 社媒截图 / Social Media Screenshot

- ID: `screenshot`
- 父族: `screenshot`
- 规模: 8 条
- 常见风格: 古风国风

## 适用
要仿真的小红书／朋友圈／微博／聊天记录截图时用它。
EN: Fake-but-real social feeds, chats and profile screenshots.

## 写法要点
- 锁定平台、机型与比例（iPhone 竖屏 9:16）。
- 逐区写 chrome：状态栏时间、头像昵称、正文、点赞栏。
- 所有可见文字给出具体内容和条数。
- 要求字体与间距符合该平台真实排版。

## 常见翻车
- 平台元素混用（微信界面带小红书配色）。
- 中文小字乱码，需减少文字密度。
