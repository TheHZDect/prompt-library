# 漫画分镜 / Comic & Storyboard

- ID: `comic`
- 父族: `comic`
- 规模: 64 条
- 常见风格: 动漫插画, 写实, 电影感, 清新治愈

## 适用
要多格叙事、漫画页或分镜板时用它。
EN: Multi-panel storytelling, comic pages, storyboards.

## 写法要点
- 定网格数与阅读顺序（2x2、九宫格、从上到下）。
- 每格写清画面内容与镜头（特写／中景／俯视）。
- 统一角色设定（发型、服装、标志物）防跨格变脸。
- 对白与拟声词内容给出并限制字数。

## 常见翻车
- 格与格之间角色长相漂移。
- 不分镜描述，模型把九格画成同一张图。
