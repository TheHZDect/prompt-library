## 1. 这是什么

GPT-Image 提示词检索库：用户给一句口语化描述 → 路由到提示词家族 → 取回可直接改用的原文与预览图。

- 三条数据线：`main`（主库）/ `daily`（日报）/ `kook`。
- **正文是唯一真相**，图片只供人工核验；检索靠正文，预览靠缩略图。
- 家族只按 产物 / 主体 / 人像风格 切分；场景、光线、风格标签是 facet，不参与分族。
- 对外交付物是一个 git 私库（技能包 + 正文 + 缩略图 + 工具），clone 后一条命令重建检索库。

## 6. 物理事实（动数据前必读）

- **指纹允许共享，别写"零重复"**。同指纹行三种性质：① 跨批重复 → 已标 `dup_of`（设计就是只标注不删）；② d0520/d0527/d0611 三组是历史手工复制（为容纳多张配图），**裁定不合并**——删行会让按位置生成的 `entry_id` 整体位移，连带缩略图、registry、gold、collection 全错位；③ 少数仅标点/大小写有别（`fp` 归一化掉了标点）。现查：`SELECT COUNT(*), COUNT(DISTINCT text_fp) FROM cases`。
- `portrait_real` 是兜底族不是流派，内部 style 多样是设计使然。`photo_misc` 兜底族已全量核查过是干净的（落进去的都是无主体模板）。
- 场景 facet 只认定域证据（core/style 段），产物类族覆盖率近 0% 属正常。
- 生成期结构约束（2026-09-01 已落库为列，判据在 `famlib.aspect_state/needs_input`，全库实测可复现）：`aspect_state` 三态 explicit=1076(9.0%) / slot=8 / none=10882；`needs_input`=342(2.9%)（参考图词 ∪ 【】槽位 ∪ {argument}；JSON 花括号是数据不算）。旧的"2.6%/4.1%"口径出自已不可考的第一次普查，以本行为准。**只有 `aspect_ratio` 值得单独成列且必须三态**；参考图与槽位只配成一个 flag 列。
- 正文清洗词最短长度门槛 10 不可降（子串匹配会清空含句号的正文）。
- `collect_noref` 的 `rel` 保持 `daily/<批次>` 形态：`collection/index.tsv` 历史行的 `from_dir` 用的是它，改了破坏幂等。

## 7. 硬规则（25 条）

1. 关键词必须定域匹配：主体只看「核心元素」段前 60 字，风格只看「画面风格」段，产物标记只认正文头/指令窗口。
2. 分类与路由禁用单字中文关键词（`花`→头发、`宫`→宫崎骏）；需排除用负向断言 `蝴蝶(?!结)`。检索侧例外：`SUBJECT_MONOGRAMS` 只放宽召回。
3. 同义组内 OR、原始词之间 AND；FTS5 trigram 只匹配 ≥3 字，2 字词回退 LIKE，同组长短词必须同时参与。
4. 路由闸门：无人物词罚 `portrait_*`(−7)；有明确主体时其它 `photo_*` 命中背景词也 −5；产物族无产物意图 −8。
5. PowerShell `-eq/-ne` 是文化敏感比较，零权重字符被判空串整行丢弃；序号比较只用 `[String]::CompareOrdinal`。`char_len` 是 UTF-16 code unit 数。
6. Python csv 读 TSV 必须 `quoting=csv.QUOTE_NONE`，否则凭空改坏正文、产生假 QC 失败。
7. 评测查询生成：先按标点切短语、短语内取片段、DF ≤2% 滤套话，且显式包含 2 字词、单字主体词、跨类组合词。
8. `dict.get(k, <调用>)` 第二参数立即求值。
9. 无提示词的图不进可检索条目库；任何一次重建后必须重跑 `collect_noref.py --apply`。
10. 相关性打分含全文出现次数时必须按正文长度归一（`/(1 + char_len/600)`）。
11. 词表分组两种性质：同一标签的不同表述（可作同义组）vs 同一判别规则的并列特征（绝不可）。
12. 识别词表与扩展词表必须分开（`VOCAB` 宽、`SYN` 严）。
13. 查询片段原样命中正文是最强相关性证据，权重远高于词频。
14. 分类维度必须是"会改变写法的东西"。判据：并进父族后成员写法分布有无变化？没变化就不配成为族。
15. 语境排除词不能含风格后缀词（'质感'、'周围' 这类高频风格/版式措辞会误伤），只取材质与地点名物词。
16. `zip` 按短序列截断：带哨兵的 `zip(seg, cover+[True])` 必须两侧等长，否则哨兵取不到、末段永不冲刷——表现是"改了完全没生效"。
17. 长尾实体词不枚举进任何词表，用文档频率判据自动识别（`phase2c_df.py`）。
18. 仪表的标注者不得同时是规则改动者；与原则冲突的条目原样留着交人工看图裁决，否则读数失真。
19. 本体词必须同时出现在族判定词表里（`STYLE_NOUNS` 与 `PORTRAIT_STYLE_PRIORITY` 是两张表）。已做成 phase3 硬校验，非空即拒绝产出。
